# Анализ компаний Y Combinator

Исходные характеристики активных компаний июля 2023 года сопоставляются со статусами августовской версии каталога 2026 года. Основание датировки позднего файла и его контрольная сумма записаны в `data/source_provenance.json`: файл скачан автором в середине августа, а 1 августа обозначает версию по графику ежемесячных обновлений источника, не точное время сбора всех строк.

## Воспроизведение

Из корня проекта, в окружении с зависимостями из `requirements-modeling.txt`:

```bash
.venv/bin/python src/data_preprocessing.py
.venv/bin/python src/eda_analysis.py
.venv/bin/python src/modeling.py
.venv/bin/python src/modeling_report.py
.venv/bin/python -m pytest -q
cd coursework_text
latexmk -pdf -interaction=nonstopmode -halt-on-error coursework.tex
```

`modeling.py` выполняет полный вложенный эксперимент: по пять групповых и случайных повторов для 14 моделей, а затем по пять групповых повторов для шести моделей на двух дополнительных совокупностях (без IK12 и без публичных компаний). Выполнение требует времени. Повторно запускать обучение для одной правки оформления не нужно: `modeling_report.py` строит таблицы и рисунки по сохранённым прогнозам и проверяет завершение всех экспериментов, контрольные суммы кода и когорты.

## Результаты и методические проверки

Основные артефакты находятся в `artifacts/modeling/team_2023_2026/`:

- `protocol.json`, `suite_complete.json` — параметры, версии библиотек, контрольные суммы и завершение полного расчёта;
- `outer_splits.csv`, `inner_splits.csv`, `split_diagnostics.csv` — части проверки и попарный ARI повторов;
- `predictions.csv`, `tuning.csv` — проверочные прогнозы и внутренний выбор параметров;
- `metrics_by_fold.csv`, `metrics_by_repeat.csv`, `metrics.csv` — метрики по частям, повторам и средние;
- `comparisons.csv`, `gains_by_batch.csv` — добавление/исключение блоков, парные изменения ошибки, условные диапазоны выборки компаний и целых наборов;
- `tag_coefficients.csv`, `tag_summary.csv` — коэффициенты тегов по 25 групповым обучающим частям, частоты меток и стабильность знака;
- `without_ik12/`, `acquisitions_only/` — отдельные вложенные эксперименты чувствительности.

AP и ROC-AUC рассчитываются внутри частей и усредняются по их размерам. PR-кривые усредняются по тем же частям; AP не называется площадью под усреднённой кривой. Precision/Recall/Lift верхних 10% получаются из суммарных счётчиков внутри каждого повтора. При проверке весов классов оба варианта настраиваются по AP.

Числа в аннотации и выводах, таблицы и условные формулировки результатов генерируются в `coursework_text/sections/generated/`. Итоговый документ — `coursework_text/coursework.pdf`. Условные интервалы не учитывают переобучение; эксперимент остаётся разведочным и не заменяет независимую проверку.
