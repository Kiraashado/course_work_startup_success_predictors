# Анализ компаний Y Combinator

Текущий EDA описывает компании, активные 13 июля 2023 года, и их статусы
на 1 августа 2026 года. Все исходные признаки берутся из июльской выгрузки.
Февральская выгрузка используется только для проверки согласованности.
Отсутствующие в позднем срезе компании сохраняются с неизвестным исходом.

## Запуск

Из корня проекта в окружении с pandas, numpy, scipy, matplotlib и pyarrow:

```bash
.venv/bin/python src/data_preprocessing.py
.venv/bin/python src/eda_analysis.py
.venv/bin/python -m unittest discover -s tests -v
```

Пути исходных файлов и даты заданы в `src/config.py`.

## Результаты

- `artifacts/preprocessed/analysis_cohort.parquet`: исходная когорта с поздним статусом.
- `artifacts/preprocessed/cohort_report.json`: состояние источников, преобразования,
  проверки сопоставления и контрольные суммы исходных файлов.
- `artifacts/eda/cohort_2023_2026/`: девять рисунков в PNG и PDF, численные сводки
  в `eda_summary.json`, таблицы корреляций и статусов по группам набора.
- `coursework_text/graphics/eda/`: копии новых рисунков для LaTeX.
- `coursework_text/sections/data.tex` и `eda.tex`: актуальные описание данных и EDA.

Положительная метка `success_binary = 1` соответствует `acquired` или `public`;
`active` и `inactive` получают 0. Неизвестный статус оставляет метку пустой.
Это показатель конечного статуса, а не универсальная оценка успеха компании.

Старые результаты `dataset_a`, `dataset_b` и прежние графики не удалены, но
новые скрипты их не используют. `eda_data.parquet` является описательной
выгрузкой, а не готовым разбиением для обучения и проверки моделей.

## Первый прогнозный эксперимент

Сравниваются постоянный прогноз, логистическая регрессия и CatBoost по набору,
возрасту и характеристикам команды. География, теги и тексты в этот эксперимент
не входят. Фактически использованные версии библиотек для Python 3.13 закреплены
в `requirements-modeling.txt` и записываются в протокол запуска.

```bash
.venv/bin/python -m pip install -r requirements-modeling.txt
.venv/bin/python src/modeling.py
.venv/bin/python src/modeling_report.py
.venv/bin/python -m unittest discover -s tests -v
```

Запуск использует `analysis_cohort.parquet`, занимает несколько минут на CPU и
выполняет вложенную проверку 5 x 3: два стратифицированных повтора и одну проверку
с разделением компаний по полному коду набора YC. Все варианты используют одни
разбиения. Пропуски и параметры моделей обрабатываются внутри обучения.
SHAP вычисляется встроенным методом CatBoost только для внешних проверочных
наблюдений первого стратифицированного повтора; отдельный пакет `shap` не нужен.

Результаты находятся в `artifacts/modeling/team_2023_2026/`:

- `protocol.json`: исходные правила, контрольные суммы, сетки параметров и версии.
- `outer_splits.csv`, `inner_splits.csv`: принадлежность компаний к проверочным частям.
- `tuning.csv`: все внутренние оценки и выбранные параметры.
- `predictions.csv`: внешние проверочные вероятности каждой компании.
- `metrics.csv`, `metrics_by_repeat.csv`: метрики по схемам и повторам.
- `comparisons.csv`: парные изменения потерь и условные границы при фиксированных прогнозах.
- `shap_oof.csv`: вклады признаков, базовое значение и исходный прогноз CatBoost.
- `results.json`: результат успешно завершённого расчёта.

Во время обучения CSV сохраняются после каждой внешней части и до завершения
могут быть неполными. Повторный запуск пересчитывает эксперимент с начала.
Не запускайте построение отчёта одновременно с обучением.

Рисунки для текста копируются в `coursework_text/graphics/modeling/`, численные
строки таблиц генерируются в `coursework_text/sections/generated/`.
Раздел `methodology.tex` описывает процедуру, `predictors.tex` — результаты
первого эксперимента. Старые разделы корреляций, динамики и заключение пока
не согласованы с новой постановкой и не подтверждают результаты новых моделей.
